# HIT HIM 🥊

> A fast-paced, retro arcade boxing browser game.

[![Play in Browser](https://img.shields.io/badge/Play-HIT%20HIM-red?style=for-the-badge&logo=gamepad)](https://snehil069.github.io/Hit-Him/)

---

## 🥊 Game Overview

Punch a dodging, weaving bald fighter by targeting the **5 facial zones** across **5 progressive damage stages** before the **20-second timer** expires!

- **5 Target Points**:
  1. **HEAD** (Forehead)
  2. **LEFT EYE**
  3. **RIGHT EYE**
  4. **NOSE**
  5. **CHIN**
- **Hits Required**: 3 hits per zone = **15 total hits** to knock him out.
- **Time Limit**: 20 Seconds.

---

## 🕹️ Features

- **Continuous Dynamic Dodging**: The fighter weaves and bobs continuously across the ring, making aiming challenging.
- **Sub-Target Points**: Subtle glowing visual reticles on the face guide your punches.
- **Damage Progression**: Character transitions across 5 transparent artwork stages from fresh to completely battered.
- **High-Impact Feedback**: Screen flash, physical punch recoil, flying spark particles, and comic popups (`WHACK!`, `POW!`, `BAM!`).
- **Responsive Zero-Latency Audio**: Multi-channel audio pool for rapid punching moans, knockout sound, and time-out defeat sound.
- **Mobile & PC Ready**: Optimized for desktop and phone screens with dynamic viewport (`100dvh`), zero-latency touch, and touch-action protections.
- **Hitbox Debug Guide**: Press **`D`** on desktop at any time to toggle the visual hitbox guide.

## 🚀 How to Run Locally

### Option 1: Direct File
Simply double-click `index.html` in your browser.

### Option 2: Local Server
```bash
# Start server
node server.js
# Or
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Play Online (GitHub Pages)

Enable GitHub Pages in your repository settings:
1. Go to **Settings** > **Pages**.
2. Under **Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. The game will be playable at: `https://snehil069.github.io/Hit-Him/`
